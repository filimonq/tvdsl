# Отчёт HW04

## Реализация

Входной текст проходит существующие HW01–HW03. Генератор получает AST с типами,
разворачивает выражения в трёхадресный код, создаёт метки и переходы для условий,
циклов и короткого замыкания логики. Поддержаны функции, рекурсия, кортежные вызовы,
массивы, неявный возврат результатов. Аннотации спецификации сохраняются в IR.
Формат и API описаны в [README.md](README.md).

Блоки строятся по меткам и границам переходов; CFG содержит предшественников и
преемников. Живость вычисляется до неподвижной точки по всему CFG, включая циклы.
Сами преобразования ограничены блоком: распространение/свёртка констант, распространение копий,
алгебраические упрощения, CSE и удаление мёртвых вычислений. DCE учитывает
живость на выходе блока и сохраняет потенциально ошибочные операции и вызовы.

Граф конфликтов содержит активные временные. Раскраска жадная, с детерминированным
порядком по степени и имени; число цветов не ограничено, spill не реализован.
Раскраска предоставляется как карта для следующего этапа, физическое размещение
значений и генерация байт-кода в эту работу не входят.

## Измерения

Получены при запуске с включёнными `const,copy,algebra,cse,dce`:

| Пример / функция | Инструкции до → после | Временные до → после | Блоки до → после | Цвета до → после |
| --- | --- | --- | --- | --- |
| arithmetic / main | 13 → 3 | 7 → 2 | 1 → 1 | 2 → 1 |
| control / main | 17 → 17 | 5 → 5 | 7 → 7 | 1 → 1 |
| calls_arrays / adjust | 8 → 5 | 4 → 4 | 1 → 1 | 1 → 2 |
| calls_arrays / main | 9 → 6 | 6 → 6 | 1 → 1 | 2 → 3 |
| contracts / main | 10 → 9 | 3 → 3 | 4 → 4 | 1 → 1 |

В `arithmetic` вычисляется константа `c=5`, удаляются запись в `dead` и её
вычисление, повтор `a+b` заменяется копированием, выражение `c*0` упрощается.
Распространение копий заменяет чтения исходными источниками, после чего DCE
удаляет цепочки копирований, включая `%t6=%t4`. Остаются три инструкции:

```text
%t2 = a + b
%t4 = %t2 + %t2
return %t4
```

Число исполняемых инструкций уменьшается на 10 (примерно на 77%).
Дампы и графы сохранены в `output/arithmetic` и `output/control`.

В примере управления локальные преобразования не находят оснований
для сокращения. В вызовах и массивах удалены копирования. При этом число цветов
временных может увеличиться: после удаления копий их значения дольше остаются
во временных вместо исходных переменных, которые в граф раскраски не входят.
Константы и копии через границы блоков не распространяются, циклы
не разворачиваются, переходы и недостижимые блоки не удаляются. Числа показывают
эффект выбранных проходов, а не время выполнения или минимально возможную раскраску.

## Проверки

Фактически выполнены:

```sh
python3 homeworks/hw04/src/main.py test
python3 homeworks/hw03/src/main.py test
python3 homeworks/hw02/src/main.py test
python3 homeworks/hw01/src/main.py test
```

Результат: HW04 — 42 тестовых метода, HW03 — 29, HW02 — 25, HW01 — 9;
все проходят. Подготовленные программы, аргументы, результаты и ошибки
хранятся непосредственно в тестах Python. Демонстрационные файлы также проверяются.
Код предыдущих домашних работ не изменялся.
Все 8 сохранённых DOT-файлов дополнительно успешно обработаны Graphviz (`dot -Tsvg`).

Проверки HW04 включают:

- структуру и типы IR из аннотированного AST, отсутствие коллизий имён временных;
- подготовленные программы с ожидаемыми результатами, ошибками компиляции
  и исполнения в тестах Python;
- все 32 комбинации включения пяти оптимизаций на арифметике, ветвлениях,
  циклах, логике, рекурсии и массивах с заранее заданными результатами;
- int32, переполнение, округление деления к нулю, особый случай `INT_MIN/-1`;
- прямую/взаимную рекурсию, вызовы вперёд, множественные результаты и порядок аргументов;
- копирование массивов, независимость копий и сохранение входных данных;
- сохранение ошибок деления и индексации даже при неиспользуемом результате;
- эффект каждого набора проходов, инвалидирование CSE при перезаписи операнда,
  отсутствие переноса констант между ветками, идемпотентность полного прохода;
- удаление копирований арифметического примера, отдельное отключение `copy`,
  перезапись источника и получателя копий, сохранение значений массивов,
  границы блоков и взаимодействие CSE с подстановкой копий;
- CFG с известными рёбрами, живость через обратное ребро цикла, граф конфликтов
  с известными рёбрами и проверку различия цветов у всех соседей;
- сохранение всех пяти видов `spec`, диагностику неподдерживаемого исполняемого квантора;
- 50 воспроизводимых арифметических фрагментов с отдельным эталоном на Python;
- 100 воспроизводимых программ с циклами, вложенной логикой, вызовами, массивами
  и переполнением: сравнение с независимым интерпретатором AST на трёх наборах
  входов при всех 32 наборах проходов (9600 сравнений);
- исполнение этих программ до/после оптимизаций с заменой временных одного
  цвета общим местом хранения (600 сравнений с AST); отдельный расчёт живости
  по инструкциям совпадает с результатами расчёта по базовым блокам;
- 200 дополнительных программ непосредственно в IR с перезаписями операндов
  и мест хранения результатов, включая копирования: 6400 сравнений,
  включая совпадение ошибок деления;
- ошибки предыдущих этапов, лимиты интерпретатора, CLI, экспорт DOT/JSON и
  исполнение восстановленного JSON из другого рабочего каталога;
- текстовый вывод всех команд, JSON по флагу и отказ `verify` от успешного
  сравнения при неправильном имени функции, аргументах или лимите.

## Сверка с условием HW04

| Требование | Реализация и проверка |
| --- | --- |
| IR из аннотированного AST HW3 для выражений, ветвлений, циклов, вызовов/возврата | `ir.generate`, независимое сравнение выполнения AST/IR; возврат объявленных результатов в конце функции |
| Базовые блоки и CFG | `flow.build_cfg`, проверка точных рёбер ветвления и живости циклов |
| Локальные константы, алгебра, DCE | `optimize`, все 32 набора проходов, сохранение результатов и ошибок |
| Опциональный CSE | Реализован, проверены повторные выражения и перезаписи |
| Живость, граф конфликтов, жадная раскраска временных | `flow`, известный граф, независимая живость по инструкциям, выполнение с общими местами хранения |
| Включение/отключение оптимизаций | `--passes`, `--no-opt`, CLI-тест отсутствия изменений при выключении |
| IR до/после, CFG, граф конфликтов | Текстовый вывод, JSON и экспорт DOT до/после |
| Положительные вычислительные примеры, ветвления и циклы | `examples`, сохранённые выходы, тесты и сравнение выполнения |
| Инструкции/временные до и после, число цветов | Таблица CLI, `analysis.txt`, `analysis.json`, таблица измерений выше |
| README: формат IR, флаги и запуск; API для кодогенерации | README содержит инструкции, операнды, метки, типы и API |
| Примеры выходов, графы и краткий отчёт об эффекте | `output/arithmetic`, `output/control`, настоящий отчёт |

Все обязательные пункты условия покрыты; CSE выполнен дополнительно.
Исполнение кванторов и генерация JVM-байткода условием HW04 не требуются.
Режим без исполнения спецификаций и принятый порядок логических операций
описаны в README; общая корректность не выводится только из факта прохождения тестов.

Дополнительно сравнены выполнения демонстрационных программ:

| Пример | Аргументы | Результат до и после |
| --- | --- | --- |
| arithmetic | `[2,3]`, `[-2,9]`, `[2147483647,1]` | `[10]`, `[14]`, `[0]` |
| control | `[0]`, `[3]`, `[8]` | `[0]`, `[3]`, `[13]` |
| calls_arrays | `[[4,8]]`, `[[-1]]` | `[11]`, `[0]` |
| calls_arrays | `[[]]` | одинаковая ошибка выхода за границы массива |
| contracts | `[[9]]` | `[9]` в режиме без исполнения спецификаций |

Сравнение на тестовых входах не доказывает общую эквивалентность. Ограничения:
нет SSA, межблочного распространения констант/копий, SMT, исполнения кванторов,
runtime-проверок контрактов и сохранения диагностики неопределённого поведения.
Раскраска абстрактная, не применена к физическим регистрам или JVM-слотам.
