# Проверка грамматики LL(1)

Источник: `grammar.bnf`. FIRST — чем может начаться правило; FOLLOW — что может идти после него.
`epsilon` означает пустую последовательность, `$` — границу после стартового правила.

Проверено правил: 51. Конфликтов выбора: 0.

Для каждой альтернативы тест сравнивает FIRST, добавляя FOLLOW, если возможен epsilon.
Множества выбора альтернатив одного правила не пересекаются.
